<h1 align="center">TextToScratch</h1>
<p align="center"><b>Write TypeScript in Scratch.</b><br>
Typed code in, real Scratch blocks out, with a game engine built in.</p>

---

- **Real type checking:** the actual TypeScript compiler catches typos in sprite, costume and sound names before anything runs.
- **Real Scratch:** the output is an ordinary `.sb3` that you can open, share and remix on Scratch or TurboWarp.
- **Game engine:** input, physics, collisions, cameras, animation, classes, pen-drawn 3D and online multiplayer over cloud variables.
- **Code anywhere:** a browser extension that puts an editor inside Scratch, a VS Code extension with a live game viewer, and a CLI.
- **Blocks to text:** convert existing Scratch projects into TypeScript and keep going.

Made something with TextToScratch? Share it in the [Discord](https://discord.gg/AnsrYzRXar) or add it to the [Scratch studio](https://scratch.mit.edu/studios/52025574)!
